= Antora Keys

The playbook keys configured under `antora` configure the Antora site generator, specifically Antora extensions.

[#antora-key]
== antora key

The `antora` key hosts the collection of registered Antora extensions.

.antora-playbook.yml
[,yaml]
----
antora: # <.>
  extensions: # <.>
  - ./lib/audit-pages-extension.js # <.>
  - require: '@antora/lunr-extension' # <.>
    index_by_heading: true # <.>
----
<.> Optional `antora` key
<.> Optional `extensions` key
<.> Path to a local extension script
<.> Path to an extension that accepts configuration
<.> A configuration key for an extension

[#antora-reference]
== Available Antora keys

[cols="3,6,1"]
|===
|Antora Keys |Description |Required

|xref:antora-extensions.adoc[extensions]
|Accepts a list of Antora extensions.
Each entry can either be the require path of an extension, or it can be a map if subkeys to register and configure that extension.
|No
|===
